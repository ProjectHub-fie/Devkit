API Tester

Security & Inspection

JWT decoder, hash identify/compare, URL parser, sensitive-data redaction.

Private by design

  • No account required, and no developer backend.
  • Local tools never make a network request.
  • API requests go straight from your device to the endpoint you enter — nothing is proxied.
  • Authorization headers and tokens are redacted in history, previews, and exports by default.
  • TLS validation is never disabled and cleartext HTTP is blocked.

Install it

  1. Download the APK from the latest GitHub release.
  2. Open the file on your phone and allow installs from this source when Android asks.
  3. Tap Install, then open Dev Kit from your app drawer.

Android 8.0 (API 26) or newer. The current download is a debug-signed build for sideloading; it installs and runs normally but is not a Google Play release.

Dev Kit is not published to Google Play. The APK is distributed through GitHub Releases, and this page is a static project page hosted on Cloudflare Pages.
